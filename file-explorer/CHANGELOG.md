# Changelog

## 0.1.1 (2026-11-09)

- **Files** on the New thread screen: the side panel's Actions list there
  shows the tree of the folder the new thread will work in, following the
  composer's project and environment. An existing environment shows its own
  folder; a project checkout, a new worktree or another new environment shows
  the project's folder on the selected machine, with a note when the thread
  will start from a copy of it.
- The tree header shows the current branch.

## 0.1.0 (2026-11-09)

- First release: a **Files** action in the thread side panel with a Cursor /
  VS Code style tree of the workspace, Seti file icons, git colors and
  letters, ignored files dimmed, an inline file preview beside the tree, and
  keyboard navigation.
- Needs BB 0.49 and plugin SDK 0.6.132.
