Keep each project one click away in the sidebar's left rail.

## What you get

- An icon per project under Home in the rail: your own PNG, an emoji, or a
  colored monogram.
- Click a project to focus the thread list on it; click again to show all.
- Cmd/Ctrl-click a project to start a new thread there; New thread in the
  header files new threads in the focused project.
- A dot on each icon when a thread in that project needs input, failed, is
  unread, or is working.
- Drag icons to reorder projects. Right-click an icon to move it, hide it
  from the rail, or give the project a home page: a plugin panel that opens
  when you click the icon.
- Home shows threads grouped by project, or one list with each thread's
  project icon.

## How it works

Focusing drives bb's built-in Thread list through its preferences: organize by
project and hide other projects into More. Showing all restores your previous
layout. Icons live in this plugin's storage; nothing leaves the machine.
